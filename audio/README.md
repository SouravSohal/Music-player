# Audio Directory

This directory should contain your MP3, WAV, or OGG audio files.

## Instructions

1. Place your audio files in this directory
2. Update the `playlist` array in `script.js` to reference your files
3. Example: If you have a file named `mysong.mp3` in this directory, reference it as `audio/mysong.mp3` in the playlist

## Supported Formats

- MP3 (`.mp3`)
- WAV (`.wav`) 
- OGG (`.ogg`)

## Note

Audio files are not tracked by git (see `.gitignore`). Users should add their own audio files to this directory.
